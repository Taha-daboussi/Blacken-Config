# design: <repo>

A chunk of `~/.config/dispatch/<name>/BLACKFILE.md`. Read it before a UI task (the expected result, the build, a design question).

## Design sources

- The sources in order (client or boss instructions, a token list, reference apps), and where to ask when no source answers.
- Tools: for example a mockup tool and a token check.

## Screen variants

- Widths: the desktop and the phone size of the two e2e passes, for example `desktop 1440x900, phone 390x844`, or `none` (a chat bot, a CLI: one pass).
- Themes: for example `light, dark (prefers-color-scheme)` or the steps of the theme switch, or `none`.
